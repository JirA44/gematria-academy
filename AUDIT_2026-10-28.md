# Whole-site audit — 2026-10-28

## Scope

The repository contains 220 HTML documents, 79 configured production routes, and the language selector for French, English, Chinese, Hindi, Spanish, Arabic, Bengali, Portuguese, Russian, and Urdu. The audit covered local route references, page metadata/structure, canonical sitemap coverage, robots sitemap URL, external links opened in new tabs, response headers, and existing GitHub Actions / deployment status.

## Changes prepared

- Added page title, language, viewport, description, and a semantic H1 to HTML documents that lacked them; standalone snippet files now have a complete document shell and are marked noindex.
- Marked demos, legacy alternate homepages, account pages, and version copies noindex to keep them out of search indexing.
- Curated sitemap.xml to 70 canonical public routes and corrected robots.txt to point to the canonical sitemap host.
- Added rel="noopener noreferrer" to new-tab links in the theme preview.
- Replaced the legacy XSS header with HSTS.
- Added a CI check that enforces metadata coverage and exact canonical sitemap coverage for all HTML files.

## Findings and limits

- The repository scan found no broken local references in the 220 HTML documents.
- Static checks can verify markup and URLs in source, but this GPTapp session does not expose an interactive browser tool. A human browser pass through every interactive flow was therefore not completed.
- Firestore rules in the repository are owner-only, but the production Firebase rules deployment could not be confirmed or run without an authenticated Firebase CLI session. Project: gematria-academy-ed04c. After Firebase CLI login, deploy with: firebase deploy --only firestore:rules --project gematria-academy-ed04c.
- 162 HTML pages contain inline event handlers. A blanket conversion would risk changing page behavior and CSP; this audit records it for a focused, page-by-page remediation.
- AI translation is machine generated and should be reviewed for specialist terminology and RTL rendering.
