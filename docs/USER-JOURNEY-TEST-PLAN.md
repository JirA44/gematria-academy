# Gematria Academy — audit fonctionnel
Les premiers tests Playwright vérifient uniquement le chargement de l'accueil, les erreurs JavaScript non interceptées et l'affichage mobile. Ils ne valident pas les comptes ou la pédagogie.
## Prochains parcours
Inscription avec comptes synthétiques sur environnement de test ; connexion, déconnexion, expiration de session et récupération de compte ; quiz, réponses correctes et incorrectes ; sauvegarde et reprise de progression ; répétition espacée ; isolation des données entre utilisateurs ; interruptions réseau.
## Agent IA exploratoire
Explorer les parcours uniquement en staging, conserver traces et captures, produire anomalies reproductibles, sans comptes réels ni actions destructrices.
## Barrière de publication
Ne pas confondre CI locale réussie et site public vérifié. Bloquer la qualification « prêt » tant que les parcours critiques ne passent pas.
